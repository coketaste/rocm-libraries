How-to
======

The ``clients/samples/`` directory contains complete runnable examples:

* ``tensor_contraction.cpp`` -- 2-tensor matmul-style contraction.
* ``mps_sample.cpp`` -- chain-of-three MPS contraction.
* ``ghz_sample.cpp`` -- NetworkState gate-application sequence.
* ``cudaq_pattern_demo/`` -- the workspace-aware pipeline a typical
  CUDA-Q tensornet adapter follows.

For end-to-end test cases, see ``clients/tests/``.
