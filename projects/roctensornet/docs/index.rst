rocTENSORNET
============

`rocTENSORNET` is the AMD-native single-node tensor-network contraction
library. The function-name surface is a bijective mapping of the
cuTensorNet 2.x (cuQuantum 24.11) public C API:
``cutensornet*`` is renamed ``roctensornet_*`` with snake_case
casing.
